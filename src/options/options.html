翻译

在 platform.deepseek.com 注册后创建。Key 只保存在你本机的浏览器里，不会上传到任何地方。翻译与「模型屏蔽」都用它。
默认 DeepSeek。换成其他 OpenAI 兼容服务时，需同时在 manifest.json 的 host_permissions 里加上对应域名并重新加载扩展。

评论

开启后，点悬浮按钮进入选择模式会自动向下加载评论、按热度（点赞/转推/回复）选出前 N 条，之后仍可在操作栏手动增减。关掉则进入时不选、由你手动点或按「🔥 自动选热门」。
默认 10，最多 20。也可在操作栏里临时改，改动会记住。

敏感内容屏蔽 / 打码

开启后，会按下面的方式屏蔽敏感文字，避免转发到微信时触发审核/封号。生成时仍可在操作栏临时开关。
普通词按字面屏蔽；用 /pattern/flags 包裹按正则处理。本扩展不内置任何政治敏感词，需你自行填写。命中处用 █ 覆盖。

网页发布后端（「生成网页」用）

💡「生成网页」预览里的「发布到腾讯文档」是免配置的引导式半自动，不需要在这里设置：点它会把图文复制到剪贴板并打开 docs.qq.com，右下角向导带你新建文档、按一次 ⌘V 粘贴、设为「任何人可查看」并取回链接。链接是 docs.qq.com 域、微信内打开最友好（需先登录腾讯文档）。下面这些后端只影响「发布并复制链接」按钮。
调研结论：平台笔记类（语雀/飞书/印象笔记/公众号）都无法免费免登录一键产出「大陆可访问」链接。境内稳定链接的正解是自建后端：CloudBase（见仓库 server/cloudbase-publish/ 可直接部署的云函数）或自建香港小站。GitHub/gist 在大陆多不可访问、微信易拦，仅适合墙外接收者/存档。发微信最稳的仍是图片或复制图文。
在 github.com/settings/tokens 创建，勾选 gist 权限即可。仅存本机。
扩展会 POST { html }，期望返回 { url }。CloudBase 与 *.tcloudbase.com 域名已预置在 host_permissions；换成自建域名需把该域名加进 manifest.json 的 host_permissions 再重新加载扩展。⚠️ CloudBase 默认 *.tcloudbase.com 域名在微信内可能走「访问提示中间页」，正式分享请在 CloudBase 绑定已备案自定义域名（设为云函数的 PUBLIC_BASE 环境变量）。

更新检测

扩展会每隔约 6 小时读取 GitHub 上 main 分支的 manifest 版本号；发现新版本时，工具栏图标会显示 NEW。解压安装模式仍需你在 chrome://extensions/ 里点「刷新」或重新加载目录。
公开仓库可留空。若检查时报 404/403，说明 GitHub API 需要认证；填写一个只具备仓库读取权限的 token 即可。Token 只保存在本机浏览器里，并仅发送给 api.github.com。
